# Security policy

Report vulnerabilities privately through GitHub Security Advisories for `inclusionAI/PanelWise`. Do not open a public issue containing an exploit, API key, authorization header, private prompt, or workspace data.

Only the latest released minor version receives security fixes while PanelWise is in `0.x` development.

Trajectory mode executes model-selected actions. The built-in command filter is a guardrail, not a sandbox. Run untrusted tasks in a disposable container or virtual machine with least-privilege credentials and restricted network access.
